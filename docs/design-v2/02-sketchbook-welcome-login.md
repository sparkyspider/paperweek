# 02 — "Sketchbook Welcome" login reference

**Status: PARKED for V2. Not approved for implementation. Discuss with Mark first, only after the current look-and-feel wave has fully landed.**

Reference image: `02-sketchbook-welcome-login.png` (supplied by Mark, 2026-09-01). This is a **ChatGPT-generated mockup**, and Mark's stated reaction is: **"I really like it."** — of the parked references, this is the front-runner direction for V2 (subject to the discussion gate above).

## What it shows

A two-page sketchbook spread as a login screen. Left page: brand/mood — brush-script "Welcome" over a yellow highlighter swipe, a pencil construction grid (blueprint-style guides), a small boxed "A" logo sketch, botanical ink drawing, ink splatters, handwritten margin notes ("keep it simple", "start with ideas", a taped-on quote card). Right side: the actual login form, restrained and tidy.

## Design cues worth extracting

- **Restraint**: palette is just cream paper + black ink + ONE yellow highlighter accent. Far calmer than ref 01 — much closer to Paperweek's "fun but by no means messy" rule.
- **Form fields**: thin hand-inked rounded rectangles with small line icons (person, padlock) and an eye toggle for password visibility. Boxes, but delicate — a single fine pen line.
- **Log in button**: solid black hand-painted rectangle (rough brush edges), white serif text, small arrow →. Confident, not colourful.
- **Google login**: "Continue with Google" as a thin outlined box with the Google G — directly relevant since Google sign-in is on Paperweek's roadmap; this shows how it can sit inside the paper language.
- **"or" divider** with ink rules either side.
- **Typography mix**: large serif "Log in" heading with a rough ink underline; handwriting reserved for margin notes and the "Welcome" script. (Contrast with v1 which uses Caveat for headings/labels.)
- **Yellow highlighter** as the only accent: title swipe, "Forgot password?" underline.
- **Construction-grid pencil guides** as background texture — quiet, technical, designerly (an alternative to watercolor blobs).
- **Split layout**: brand/mood page left, functional form right — a two-page-spread metaphor.

## Relation to v1

- Uses boxed fields and a Remember-me checkbox — v1's rulings are underline-only fields and *no checkboxes*. A V2 discussion should settle: do delicate hand-inked boxes count as "paper", or do underlines stay?

## Font mapping (from ChatGPT, relayed by Mark 2026-09-01)

Caveat: the mock-up is generated imagery, so these are visual approximations, not exact matches. ChatGPT's closest real-font recipe:

- "Log in" heading → **Cormorant Garamond** or Bodoni Moda (elegant editorial serif)
- "Welcome" script → Kalam, **Caveat**, or Brittany Signature (loose ink handwriting; ideally with a custom brush/marker treatment)
- Small handwritten margin notes → **Caveat** or Patrick Hand
- Form text / UI → **Inter**, DM Sans, or Source Sans 3
- The boxed "A" construction sketch → thin geometric serif (Cormorant Garamond) + hand-drawn guide lines

ChatGPT's pick for the exact aesthetic: **Cormorant Garamond + Caveat + Inter**.

Happy accident: **Caveat and Inter are already Paperweek v1's fonts** — so a V2 in this direction would only add Cormorant Garamond as the serif heading layer, rather than re-founding the typography.
